# Car Manufacturers List

A single-page, gradient-styled list of car manufacturers with alphabetical sections and brand cards.

## What is included
- Scrollable list with A-G sections
- Sticky alphabet navigation
- Two real logos from `images/` plus fallback logo tiles

## Quick start
Open `index.html` in a browser.

## Optional scripts
If you want a quick validation pass on the structure:

```powershell
powershell -ExecutionPolicy Bypass -File tools\validate.ps1
```
